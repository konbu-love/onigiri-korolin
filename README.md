# おむすびコロリン

穴から落ちてくるおにぎりを、こまねずみ(小間使ネズミ)のザルでキャッチする、ゆるい落ちゲーです。
キャッチするほど、下で寝ているネズミのお腹が大きくなります。

## あそびかた

- 画面を指でなぞると、こまねずみが左右に動きます(PCは矢印キー左右)
- 地面に穴が出て、少しずつ深くなり、開通するとおにぎりが落ちてきます
- 制限時間は60秒。後半ほど速くなります
